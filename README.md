# Sales Data Analysis Dashboard

## Project Overview

This project analyzes sales data from the Superstore dataset to identify key sales trends, top-performing categories, regions, states, customers, and products.

The analysis was completed using Microsoft Excel with Pivot Tables, Pivot Charts, and an interactive-style dashboard.

## Dataset

- Rows: 9,800
- Columns: 18
- Dataset: Superstore Analysis
- Main business metric: Sales

### Data Categories

- Order Information
- Customer Information
- Location Information
- Product Information
- Sales

## Business Questions

1. Which category generates the highest sales?
2. Which sub-category generates the highest sales?
3. Which region has the highest sales?
4. Which states have the highest sales?
5. Which customers contribute the most revenue?
6. How do sales change over time?
7. Which products are top-selling?

## Key Findings

- Technology generated the highest sales among the three categories.
- Phones were the highest-selling sub-category.
- The West region generated the highest regional sales.
- California generated the highest state-level sales.
- Sean Miller was the highest revenue-generating customer.
- Canon imageCLASS 2200 Advanced Copier was the top-selling product.

## Dashboard

The Excel dashboard summarizes:

- Total Sales
- Total Customers
- Total Orders
- Sales by Category
- Sales by Region
- Top 10 Customers
- Top 10 Products
- Top 10 States

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard

## Analysis Limitation

Time-series analysis was not performed in Excel due to date format inconsistencies in the imported dataset. This analysis can be addressed in a future Power BI phase using appropriate date transformation.
